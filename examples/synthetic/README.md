# Synthetic software fixture

All 20 posts, IDs, features, metrics, and consent declarations here are invented. The long
consent expiry exists only to keep offline examples runnable. It is not a retention recommendation.
No media files are included and no labels were produced by an AI model.

This fixture exercises the schema and arithmetic. It cannot validate extraction quality,
research hypotheses, production efficiency, or real-world model costs. Real consent evidence
must be stored privately and independently verified before processing actual data.
